# Chinese food knowledge data

`chinese-food-knowledge.json` is generated from the curated dish list in `scripts/generate-food-knowledge.mjs`.

Run `node scripts/generate-food-knowledge.mjs` after changing the dish list. The current data pack contains 520 dishes across 10 cuisine/restaurant-type groups. Ingredient and allergen fields describe common recipe patterns only; restaurant-specific confirmation is required for allergy decisions.
